# MA-LIFE Maternal and Child Health System

MA-LIFE manages maternal and child health records, antenatal appointments, immunizations and child growth monitoring.

## Docker deployment

Create a server-only `.env` with separate strong values for `DB_PASSWORD` and `DB_ROOT_PASSWORD`. Set `BASE_URL` to the HTTPS origin when using a different hostname. Run `docker compose up -d --build` and point the HTTPS reverse proxy at `127.0.0.1:18941`. For a restricted preview, configure the preview endpoint with the server-only variables `PREVIEW_USER`, `PREVIEW_PASSWORD_HASH` (a PHP password hash), and `PREVIEW_SIGNING_KEY` (at least 32 random characters). Use the preview endpoint’s `?check=1` response for internal proxy authorization checks. Overwrite `X-Forwarded-Proto` with the actual request scheme.

The MySQL and upload volumes persist across container replacements. Database initialization creates tables without importing existing records or accounts. Provision the first administrator through the server using a PHP password hash generated by `password_hash`. Public signup supports the mother or guardian role. Configure the SMS service with server-side environment variables before sending messages.
